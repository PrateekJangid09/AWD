# Palette Fixer V15.3

## Theme rollback

The V15.2 orange/cream product chrome has been rolled back to the previous neutral frosted-glass theme.

Preserved from V15.2:

- accepted suggestions remain protected and role-locked
- locked suggestions survive **Fix Palette**
- relationship-aware explainable engine
- honest partial preview and repaired five-role preview
- preview eligibility/state fixes
- V15.1 security dependency patch
- AW logo assets and header logo

The AW logo remains as the brand identifier, but the application background, buttons, cards, tabs, focus states, and analysis UI are no longer orange-tinted.
