What is Colorhyme?

Colorhyme is for the moment after you have chosen a color.

Instead of generating a completely new palette, it keeps your starting color visible and lets you move from it deliberately. Shift the hue by an exact angle, reduce saturation, darken the color and compare the results side by side.

Every transformation is controlled by visible values, so a color relationship can be reproduced instead of rediscovered later.

Hue relationships

Move around the color wheel deliberately.

Hue is measured as an angle around a color wheel. A small shift keeps the result close to the original hue. Larger shifts create a more obvious relationship.

Common starting points include 30° for a nearby hue, 120° for a triadic relationship, 137.5° for the golden-angle preset and 180° for the opposite hue. These are starting relationships, not guarantees of a good palette. Saturation, lightness, contrast and context still matter.

HSL precision

Exact values. Different perception.

Colorhyme uses deterministic HSL transformations, so the same input and settings produce the same numerical result every time. HSL is intuitive, but it is not perceptually uniform. An equal numerical shift can look stronger in one part of the color space than another.

Frequently asked questions

Useful details before you use it.

Is Colorhyme a palette generator?

Not in the usual sense. It starts with a color you already have and creates controlled related colors from it.

What does hue shift mean?

Hue shift moves a color around the color wheel by a specified number of degrees.

Can I enter an exact hue angle?

Yes. Colorhyme supports numerical input to 0.1°.

What does the 137.5° preset do?

It applies a 137.5° hue shift, close to the mathematical golden angle. It is a starting relationship, not a guarantee of harmony.

Does Colorhyme create a perfect palette?

No. Final quality still depends on context, saturation, lightness, contrast and usage.

Does Colorhyme use AI?

The core transformation engine does not need AI. It uses deterministic color calculations.

Is Colorhyme free?

The core transformation workflow is designed to remain free.

Are colors uploaded?

No server processing is required for the core calculations. They run locally in your browser.

Is HSL perceptually uniform?

No. HSL values are repeatable, but equal numerical changes do not always look equally strong.
